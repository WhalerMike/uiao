Provision DDI-backed subnet

Trigger + 8 actions · runs as the app service account · MID Server in-boundary. Mirrors Chapter 7 §7.1 and flow/flow-blueprint.md.
Trigger
Service Catalog — item submitted
“Request a DDI-backed subnet” · inputs mapped to module tfvars
▼
1 · Approval
Ask for approval (SoD gate)
Approvers = Network / DDI group · reject → close cancelled
▼
2 · Script (InfobloxDDIClient)
Allocate CIDR / next-available IP
nextAvailableIp(requested_cidr, network_view)
▼
3 · CPG Terraform Connector
Plan → approve → apply ../terraform
runs on MID Server · Key Vault secret refs resolve on MID
▼
4 · Script (InfobloxDDIClient)
Register DNS (A + PTR)
createHostRecord(fqdn, ip, dns_view)
▼
5 · Script (InfobloxDDIGate)
Validation gate — pass/fail
runGate() → dns / discovery-sync / ipam-conflict · fail → back to step 1
▼
6 · Service Graph Connector
CMDB reconcile
cmdb_ci_ip_network / _subnet attached to the request
▼
7 · Close
Request closed complete
audit trail = approvals + plan + validation JSON (AU-2/AU-6/AU-12)
