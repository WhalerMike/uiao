# UIAO Release Notes

Release history for UIAO — the Unified Identity & Access Orchestrator — is
maintained in two canonical places:

- **[`CHANGELOG.md`](https://github.com/WhalerMike/uiao/blob/main/CHANGELOG.md)**
  — the per-release record of every notable change (Keep-a-Changelog
  format). The `[Unreleased]` section at the top tracks what has landed on
  `main` since the last release.
- **[GitHub Releases](https://github.com/WhalerMike/uiao/releases)** — tagged
  releases with downloadable artifacts and SHA-256 checksums, including the
  standalone kits (Federal AAN, UIAO CLI, Windows Server).

This file intentionally carries no per-release detail of its own: earlier
revisions duplicated the changelog and drifted stale (a March 2026 revision
still described the pre-consolidation "Modernization Atlas" — see ADR-032
for the single-package consolidation that superseded that shape). The
changelog is the single source of truth.
