What this determination is, and is not

This document records the architecture review's finding that the design is TIC 3.0 conformant and that campus policy enforcement point capabilities have been accounted for at the branch. It does not accept risk. The single item requiring risk acceptance — the Optimize-category inspection exemption — is referred to the Authorizing Official in the covering memo. Keeping those two decisions separate is what allows each signer to answer a question that is actually theirs.

B1 — Security pattern classification

The Branch Office Use Case defines three patterns. An agency may implement a subset. Classification is not bookkeeping: it determines which policy enforcement point capabilities apply, and a misclassification here propagates into every row of B2.

Branch Office to Cloud Service ProviderProposed Branch users reaching an agency-sanctioned CSP. Microsoft 365 is a sanctioned service under [reference], which places locally egressing Optimize traffic in this pattern.
Branch Office to Web Generic internet destinations. Selecting this pattern for Microsoft 365 pulls in a general web-proxy capability set whose inspection expectations are incompatible with the Optimize category's purpose.
Branch Office to Agency Campus Branch access to internal resources. Applies to the site's other traffic and is unchanged by this design; recorded here for completeness.

Confirm the group list against the version you cite

The twelve groups above reflect the later catalog revisions, which carry Unified Communications and Collaboration, Data Protection, Services and Identity in addition to the original set. The group list has grown across versions — an earlier catalog carried eight — so the count is a property of the version, not of TIC 3.0. Enumerate from the catalog revision named in the header and correct this table if it differs.

As of this drafting the current revision appears to be v3.3 (July 2025), superseding v3.2, which superseded v2.0. Several superseded copies rank highly in search results; confirm the version before the review convenes.
